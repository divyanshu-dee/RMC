# 🎮 Raja Mantri Chor Sipahi - Multiplayer Web Game

🚀 A real-time multiplayer version of the classic childhood game **Raja Mantri Chor Sipahi**, built using modern web technologies.

---

## 🌐 Live Demo

👉 https://divyanshu-dee.github.io/RMC/

---

## 🎯 Features

* 👥 4 players can join using a room code
* 📱 Play from different devices (phones/laptops)
* 🎭 Random role assignment (Raja, Mantri, Chor, Sipahi)
* 🔄 Real-time updates using Firebase
* 🧠 Mantri guesses the Chor
* 🏆 Instant result display

---

## 🛠️ Tech Stack

* HTML
* CSS (Glassmorphism UI)
* JavaScript
* Firebase Realtime Database
* GitHub Pages (Hosting)

## ⚙️ How to Run Locally

1. Clone the repository

```
git clone https://github.com/divyanshu-dee/RMC.git
```

2. Open the folder

3. Run `index.html` in your browser

---

## 🔥 How to Play

1. One player clicks **Create Room**
2. Share the room code with 3 other players
3. All players join the room
4. Roles are assigned automatically
5. Mantri guesses who is the Chor
6. Result is displayed 🎉
